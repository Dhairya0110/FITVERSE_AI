# FitVerse AI -- YouTube Recipe Integration Feature

## Overview

Add a **Watch Recipe** feature below every meal in the AI Diet Planner.
Users can tap a button to open a YouTube recipe demonstrating how to
prepare the recommended meal.

## Objectives

-   Help users prepare meals correctly.
-   Improve user engagement.
-   Eliminate manual recipe searching.

## Features

-   Watch Recipe button below each meal.
-   Open recipe in YouTube or embedded player.
-   Multiple recipe options per meal.
-   AI-generated meals linked with relevant recipes.

## Example

### Breakfast

**Oats with Banana & Milk**

-   Calories: 420 kcal
-   Protein: 18 g
-   Carbohydrates: 55 g
-   Fat: 10 g

Buttons: - ▶ Watch Recipe - 📋 Ingredients - 🍳 Cooking Steps - 🔄
Alternative Recipes

## Additional Information

-   Cooking time
-   Difficulty level
-   Ingredients list
-   Step-by-step instructions
-   Nutritional information

## Functional Requirements

1.  Every meal includes at least one recipe link.
2.  Support multiple recipe links.
3.  Open YouTube in browser or in-app.
4.  Handle unavailable recipes gracefully.
